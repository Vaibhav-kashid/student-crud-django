# Student CRUD (Django)

A Django web app to manage student records with Create, Read, Update and Delete operations.

## Tech Stack
- Python
- Django
- SQLite
- HTML templates

## How to Run
1. Clone the repository: `git clone https://github.com/Vaibhav-kashid/student-crud-django.git`
2. Go into the folder: `cd student-crud-django`
3. Install Django: `pip install django`
4. Apply migrations: `python manage.py migrate`
5. Start the server: `python manage.py runserver`
6. Open http://127.0.0.1:8000/ in your browser
